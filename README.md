# Eraya: Delhi Café

You are a world-class senior web designer, creative director, UX strategist, and frontend engineer with 15+ years of experience creating premium websites for restaurants, cafés, hospitality brands, and lifestyle businesses. Design and build an outstanding premium website for “Cafe Eraya” in New Delhi. The website must feel like it was designed by a high-end professional branding and web design agency — not AI-generated, not template-like, not generic, and not cyberpunk. The overall visual direction should be: Elegant • Warm • Modern • Premium • Appetizing • Editorial • Sophisticated • Human • Delhi Café Culture 1. BRAND DIRECTION Brand: CAFE ERAYA Location: Mohan Garden / Dwarka Mor, New Delhi Address: Shop No. 3, 80A, K-1 Extension, Shani Bazar Chowk, Gurudwara Road, Block M, Mohan Garden, Hastsal, New Delhi – 110059 Cuisine: • Indo-Chinese • Continental • Desserts • Chaat • Healthy Food Approximate cost for two: ₹500–₹800 Primary objective: Turn website visitors into customers. The website should strongly encourage: • Book a Table • Reserve a Seat • View Menu • Order Now • Call Cafe • Get Directions • Explore the Café • Discover Signature Dishes 2. VISUAL STYLE Create a sophisticated RED + WHITE café identity. Primary colors: • Soft Light Red • Elegant Warm Red • Off-White • Cream • Soft Beige • Deep Burgundy for typography/accent • Very subtle charcoal Suggested palette: Primary Red: #C83F45 Light Red: #E96A6F Deep Burgundy: #7E2028 Warm White: #FFFDFC Cream: #F8F2ED Soft Beige: #EFE4DC Dark Text: #211B1B Do NOT make the website overwhelmingly red. Use red strategically for: • CTA buttons • highlights • active navigation • menu accents • icons • section dividers • booking elements The majority of the interface should remain white / cream / spacious. 3. DESIGN PHILOSOPHY The website should feel like: A premium modern café photographed by a lifestyle magazine. Think: • sophisticated café branding • editorial restaurant websites • premium food photography • elegant typography • generous whitespace • subtle motion • warm atmosphere • refined layouts • tactile UI • authentic photography Avoid: • Cyberpunk • Neon • Dark futuristic interfaces • Excessive glassmorphism • Excessive gradients • Floating 3D blobs • Overused AI-style layouts • Generic startup cards • Excessive rounded containers • Huge unnecessary text • Random decorative elements • Excessive animations The website must look human-designed and brand-specific. 4. TYPOGRAPHY Use an elegant combination of modern sans-serif + sophisticated serif typography. Recommended: Headings: Playfair Display / DM Serif Display / Cormorant Garamond Body: Inter / Manrope / DM Sans Use typography with strong hierarchy. Example: Small eyebrow: WELCOME TO ERAYA Large heading: GOOD FOOD. GOOD MOOD. GOOD MOMENTS. Supporting copy: A warm and contemporary café experience in the heart of West Delhi. Typography should feel editorial and luxurious without becoming overly formal. 5. NAVIGATION Create a beautiful responsive navigation bar. Desktop: Left: ERAYA or a minimal Cafe Eraya wordmark. Center/right: • Home • Our Story • Menu • Gallery • Experience • Contact Primary CTA: BOOK A TABLE Navigation behavior: • Transparent/light background over hero • Becomes solid warm-white when scrolling • Elegant subtle shadow • Smooth transition • Sticky navigation • Excellent mobile menu Do NOT make the navbar excessively large. 6. HERO SECTION — MOST IMPORTANT Create an unforgettable restaurant-style hero section. Use a large cinematic café photograph as the visual centerpiece. Hero concept: A beautifully styled table at Cafe Eraya featuring: • steaming food • coffee • desserts • elegant plates • warm natural lighting • subtle red elements • premium café interior • realistic Delhi café atmosphere Use a sophisticated split-screen or editorial composition. Example structure: LEFT: Small text: WELCOME TO CAFE ERAYA Huge headline: WHERE EVERY BITE FEELS LIKE A MOMENT. Description: Contemporary flavours, comforting classics and beautiful moments — all served under one roof in New Delhi. CTA buttons: BOOK A TABLE → EXPLORE MENU RIGHT: Large high-quality food/café photograph with subtle rounded corners or elegant organic framing. Add a small floating information element: OPEN TODAY 11:00 AM — 10:30 PM or: ₹500–₹800 FOR TWO Keep the floating element minimal and elegant. Hero should immediately communicate: FOOD + EXPERIENCE + PREMIUM CAFÉ 7. HERO ANIMATION Use subtle premium motion. On page load: • headline fades upward • image softly scales from 1.03 → 1 • CTA buttons fade in • navigation smoothly appears • small decorative elements move slightly During scrolling: • subtle image parallax • typography reveal • gentle section transitions Animations must be: slow, elegant, natural and purposeful. Never make the site feel like a gaming website. 8. QUICK BOOKING BAR Immediately below the hero, create a beautiful booking strip. White/cream background with subtle border. Fields: DATE TIME GUESTS Primary CTA: CHECK AVAILABILITY Add: Reserve your table in a few clicks. On mobile, convert this into a compact booking card. 9. “WHY ERAYA?” SECTION Create a visually rich section introducing the café. Small label: THE ERAYA EXPERIENCE Heading: MORE THAN JUST A CAFÉ. Paragraph explaining that Cafe Eraya combines delicious food, relaxed ambience, desserts, beverages, and a welcoming environment. Create 3–4 elegant feature blocks: Freshly Prepared Thoughtfully prepared food made for every craving. Cozy Atmosphere A comfortable space for conversations, celebrations and everyday moments. Something For Everyone From Indo-Chinese favourites to continental dishes, desserts and chaat. Made For Moments Perfect for casual meetups, dates, family gatherings and friends. Use small line-art icons. 10. SIGNATURE DISHES Create a premium editorial food section. Heading: A TASTE OF ERAYA Subheading: Favourites worth coming back for. Display 4–6 signature dishes. Each card should include: • High-quality food image • Dish name • Short description • Price • Category • “Add to favourites” heart icon Categories: STARTERS | MAIN COURSE | BEVERAGES | DESSERTS Cards should NOT look like generic ecommerce cards. Use an editorial restaurant-menu layout. Example: Large image on one side. Dish information elegantly positioned beside it. Add subtle hover effects. 11. MENU SECTION Create a dedicated interactive menu. Categories: • All • Chinese • Continental • Indian / Chaat • Beverages • Desserts • Healthy Menu items should contain: Dish Name Short description ₹ Price Optional vegetarian indicator. Add: VIEW FULL MENU button. If the actual menu data is unavailable, create clean placeholder content that can easily be replaced later. 12. EXPERIENCE SECTION Create a visually immersive section: Small heading: YOUR TABLE IS WAITING Large heading: COME FOR THE FOOD. STAY FOR THE MOMENTS. Use a large interior/café image. Overlay a subtle red booking card: PLAN YOUR VISIT Mohan Garden, New Delhi 11:00 AM – 10:30 PM Dine-in Available Button: BOOK A TABLE 13. PHOTO GALLERY Create a beautiful asymmetric editorial gallery. Images: • Café interior • Food closeups • Coffee • Desserts • People enjoying food • Table settings • Café details • Exterior Use different image sizes. Do NOT create a boring equal-size grid. Use: • masonry-style layout • subtle hover zoom • elegant captions • smooth image reveal Gallery title: A GLIMPSE OF ERAYA Subtitle: Good food looks even better when shared. 14. SOCIAL PROOF Create an elegant review section. Heading: LOVED BY OUR GUESTS Display 3–5 realistic review cards. Include: ★★★★★ Customer name Short review Example: “Beautiful little café with great food and such a comfortable atmosphere. Definitely coming back.” Keep reviews visually authentic. Add rating summary: 4.8+ Loved by local diners Do not exaggerate ratings if verified data is unavailable. 15. INSTAGRAM-STYLE SECTION Create: FOLLOW THE ERAYA MOMENTS Display 6 beautiful square images. CTA: @CAFEERAYA Button: FOLLOW US Add subtle hover interactions. 16. RESERVATION SECTION This is one of the most important conversion sections. Create a beautiful full-width red section. Background: Elegant warm red / burgundy. Heading in white: YOUR TABLE IS WAITING. Supporting text: Make your next meal a little more memorable. Booking form: Name Phone Number Date Time Guests Special Request CTA: RESERVE MY TABLE Add: We'll confirm your reservation shortly. The form should be functional and validation-ready. 17. LOCATION SECTION Create a premium location section. Heading: FIND YOUR WAY TO ERAYA Show: Cafe Eraya Shop No. 3, 80A, K-1 Extension, Shani Bazar Chowk, Gurudwara Road, Block M, Mohan Garden, Hastsal, New Delhi – 110059 Buttons: GET DIRECTIONS CALL NOW Embed a clean Google Maps section. Include nearby landmark information if useful: Near Zaildar Sports Complex / Dwarka Mor area 18. CONTACT SECTION Create elegant contact information. Phone WhatsApp Instagram Opening Hours Location Use minimal icons. Opening hours: Every Day 11:00 AM — 10:30 PM Add CTA: PLAN YOUR VISIT → 19. FOOTER Premium minimal footer. Logo: CAFE ERAYA Tagline: Good food. Good mood. Good moments. Navigation: Home Our Story Menu Gallery Contact Social: Instagram Facebook WhatsApp Address Opening hours Copyright: © 2026 Cafe Eraya. All Rights Reserved. 20. FLOATING MOBILE CTA On mobile devices, create a fixed bottom action bar. Buttons: CALL WHATSAPP 🍽 BOOK TABLE Make it elegant and compact. This should significantly improve mobile conversion. 21. MICROINTERACTIONS Add refined interactions throughout the site: • button hover animations • image zoom • text reveal • smooth scrolling • menu category transitions • elegant cursor interaction on desktop • navigation transition • section reveal animations • booking form feedback • subtle parallax Use animation sparingly. The experience should feel: Premium, not animated for the sake of animation. 22. RESPONSIVE DESIGN The website must be perfect on: • Desktop • Laptop • Tablet • iPhone • Android • Small mobile screens Mobile design must NOT simply shrink the desktop layout. Create a dedicated mobile UX. Prioritize: 1. Food visuals 2. Menu 3. Booking 4. Location 5. Call / WhatsApp 23. PERFORMANCE The website should feel extremely fast. Implement: • optimized images • lazy loading • responsive images • compressed assets • minimal unnecessary JavaScript • smooth animations • code splitting • optimized fonts • SEO metadata • semantic HTML Target: 90+ Lighthouse performance Avoid heavy libraries unless genuinely necessary. 24. SEO Optimize for local search. Target keywords naturally: Cafe Eraya Delhi Cafe in Mohan Garden Cafe near Dwarka Mor Best cafe in West Delhi Restaurants near Dwarka Mor Cafe near Mohan Garden Cafe Eraya New Delhi Create: • SEO title • meta description • Open Graph image • LocalBusiness schema • Restaurant schema • FAQ schema where appropriate • sitemap • robots.txt 25. CONVERSION STRATEGY The website should constantly guide visitors toward action without becoming pushy. Primary conversion: BOOK A TABLE Secondary: VIEW MENU Third: GET DIRECTIONS Fourth: CALL / WHATSAPP Place CTA strategically: • Hero • Booking bar • Signature dishes • Experience section • Reservation section • Footer • Mobile sticky bar Use strong but elegant CTA copy. Examples: BOOK YOUR TABLE DISCOVER THE MENU PLAN YOUR VISIT GET DIRECTIONS 26. IMPORTANT — AUTHENTICITY This is extremely important. The final website must NOT look like an AI-generated website. Avoid common AI website patterns: Excessive rounded cards Random gradient backgrounds Purple/blue gradients Futuristic glassmorphism Neon effects Generic 3D illustrations Random floating blobs Excessive animations Generic stock-photo layouts Repeating identical cards Instead use: ✓ Editorial composition ✓ Strong photography ✓ Realistic café imagery ✓ Elegant typography ✓ Natural spacing ✓ Asymmetrical layouts ✓ Warm colors ✓ Subtle shadows ✓ Sophisticated interactions ✓ Real restaurant branding ✓ Human-looking content hierarchy The website should look like a premium Delhi café's actual digital brand, not a website-template demonstration. 27. VISUAL STORYTELLING The page should tell a story as the user scrolls: DISCOVER ERAYA ↓ SEE THE FOOD ↓ EXPERIENCE THE SPACE ↓ EXPLORE THE MENU ↓ SEE WHAT GUESTS LOVE ↓ FIND THE CAFÉ ↓ BOOK YOUR TABLE This should create a natural emotional journey toward reservation. 28. TECHNOLOGY Build using a modern production-ready stack. Preferred: React / Next.js TypeScript Tailwind CSS Use modern animation libraries such as: Framer Motion Only where they improve the experience. Use clean reusable components. Structure: • Navbar • Hero • BookingBar • About • SignatureDishes • Menu • Experience • Gallery • Reviews • Instagram • Reservation • Location • Contact • Footer • MobileActionBar Keep the code modular, maintainable and scalable. 29. FINAL CREATIVE DIRECTION Imagine the website opening with a beautifully photographed plate of food, warm natural sunlight entering the café, elegant red typography appearing slowly, and the words: CAFE ERAYA GOOD FOOD. GOOD MOOD. GOOD MOMENTS. The user immediately feels: “I want to visit this place.” The entire experience should feel: Warm. Elegant. Modern. Appetizing. Premium. Authentic. Delhi. Most importantly: DO NOT DESIGN A WEBSITE THAT SIMPLY LOOKS BEAUTIFUL. DESIGN A WEBSITE THAT MAKES PEOPLE WANT TO VISIT CAFE ERAYA. Every design decision should support that goal.
